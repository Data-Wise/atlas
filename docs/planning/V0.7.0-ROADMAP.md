# Atlas v0.7.0 Roadmap

**Planning Date:** 2025-12-28
**Focus:** Enhanced Focus Mode, Calendar Integration, Reporting

## Release Goals

Build on v0.6.0's session analytics with calendar awareness and improved focus features.

## Feature Candidates

### Tier 1: Core Features (Must Have)

| Feature | Description | Effort |
|---------|-------------|--------|
| **Task-Based Focus** | Set specific task before starting Pomodoro | 🔧 Medium |
| **Session Export** | Export sessions to iCal/ics format | ⚡ Quick |
| **Report Export** | `atlas stats --export md/json` | ⚡ Quick |
| **Time Block View** | Dashboard timeline view of today's sessions | 🔧 Medium |

### Tier 2: Nice to Have

| Feature | Description | Effort |
|---------|-------------|--------|
| **Calendar Import** | Import time blocks from iCal | 🔧 Medium |
| **Desktop Notifications** | Break reminders, streak alerts | 🔧 Medium |
| **Multi-Pomodoro Tracking** | Track completed pomodoros per session | ⚡ Quick |
| **Focus Sounds** | Ambient sounds during focus (white noise) | 🏗️ Large |

### Tier 3: Future Consideration

| Feature | Description | Effort |
|---------|-------------|--------|

## Proposed Implementation Order

### Phase 1: Export Features (Quick Wins)
1. **Report Export** - Add `--export` flag to `atlas stats`
   - `atlas stats --export json > weekly.json`
   - `atlas stats --export md > weekly.md`

2. **Session Export** - Add `atlas session export` command
   - Export sessions as iCal events
   - Useful for importing to calendar apps

### Phase 2: Enhanced Focus
3. **Task-Based Focus**
   - Before Pomodoro: "What will you focus on?"
   - After: "Did you complete it?" → Capture outcome
   - Track task completion rate

4. **Multi-Pomodoro Tracking**
   - Count completed pomodoros in session
   - Show 🍅🍅🍅 in session end summary
   - Stats: "Average pomodoros per session"

### Phase 3: Calendar Integration
5. **Time Block View**
   - New dashboard view (`t` key)
   - Horizontal timeline of today's sessions
   - Shows gaps and focus periods

6. **Calendar Import** (optional)
   - `atlas calendar import ~/cal.ics`
   - Creates time blocks in atlas
   - Shows in Time Block View

## Technical Considerations

### iCal Export Format
```ics
BEGIN:VCALENDAR
VERSION:2.0
PRODID:-//Atlas//Session Export//EN
BEGIN:VEVENT
DTSTART:20251228T090000Z
DTEND:20251228T093000Z
SUMMARY:Atlas Session - my-project
DESCRIPTION:Flow session (30m)
END:VEVENT
END:VCALENDAR
```

### Report Export Structure
```json
{
  "period": "week",
  "generated": "2025-12-28T15:00:00Z",
  "summary": {
    "totalSessions": 12,
    "totalTimeMs": 31500000,
    "flowRate": 0.67,
    "completionRate": 0.75
  },
  "streak": { "current": 3, "longest": 15 },
  "byProject": [ ... ],
  "byDay": [ ... ]
}
```

## Timeline

Not setting fixed dates - features completed incrementally:
1. Export features first (low risk, high value)
2. Enhanced focus next (builds on existing UI)
3. Calendar features last (more complex)

## Success Criteria

- Export works with popular calendar apps (Apple Calendar, Google)
- Focus mode captures task context
- Timeline view helps visualize work patterns
- No performance regression in dashboard
