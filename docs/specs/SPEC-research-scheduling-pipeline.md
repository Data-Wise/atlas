## Problem

The research registry and `_RESEARCH-BOARD.md` drift because nothing refreshes them on cadence:
- `com.data-wise.atlas-sync` (launchd) runs packages-only plain sync — never `--research`
- `com.data-wise.mediationverse-status-sync` (launchd) is **broken** (exit 1)
- A cloud scheduled task `research-action-board-weekly` runs Mon 09:38 but reads stale data
- `MediationVerse_Dashboard.md` is generated by a bespoke Python script instead of `obs research board`

---

## Design

### Pipeline (coherent Monday chain)

```
08:07  pmed-extensions-weekly-advance   (writes .STATUS — existing cloud task)
09:15  [NEW] research-sync-and-board    (atlas --research → obs board → vault)
09:38  research-action-board-weekly     (reads fresh registry — existing cloud task)
```

### Three components

#### Component 1 — Add Mon 09:15 launchd job (#61)

New plist `com.data-wise.research-sync-board` running:
```bash
atlas sync --research && \
obs research board --out "$HOME/Library/Mobile Documents/iCloud~md~obsidian/Documents/Research/00_meta/_RESEARCH-BOARD.md"
```

Why launchd over cloud task: this writes to the local Obsidian vault (iCloud path), which cloud agents can't reach.

#### Component 2 — Retire broken launchd mediationverse-status-sync (#62)

`com.data-wise.mediationverse-status-sync` is exit-1 (broken) AND duplicates a cloud task.  
**Decision: retire the launchd job, keep the cloud task.**  
Rationale: cloud task runs reliably without requiring Mac awake at a specific time; launchd is the broken one.

Action: `launchctl unload ~/Library/LaunchAgents/com.data-wise.mediationverse-status-sync.plist && rm ~/Library/LaunchAgents/com.data-wise.mediationverse-status-sync.plist`

#### Component 3 — Retire mediationverse-status-sync.py (#63)

`obs research board --kind package` already works (confirmed — `obs` is at `/opt/homebrew/bin/obs`).  
The Python script at `~/projects/r-packages/scripts/mediationverse-status-sync.py` can be retired once the #61 pipeline is verified over 1–2 Monday runs.

**Retirement sequence:**
1. Wire Component 1 plist (this session)
2. Verify next Monday run — check `_RESEARCH-BOARD.md` and package dashboard rendered correctly
3. Disable Python script (rename to `.disabled` or delete)
4. Unload cloud `mediationverse-status-sync` task if now redundant
