Atlas

Project State Engine for ADHD-Friendly Workflow

You never lose the thread.

Atlas tracks your projects, sessions, and context between the moment an idea lands and the moment you actually ship it. Built for brains that don't work in straight lines.

brew tap data-wise/tap && brew install atlas   # 1. install
atlas init                                     # 2. set up ~/.atlas
atlas session start myproject                  # 3. start working

The Loop

Atlas isn't a todo list. It's three habits that repeat, all day, every day — the same loop the ADHD Guide is built around.

Catch

atlas catch "idea"

Never lose a thought mid-flow.

→

Session

atlas session start/end

Work happens inside boundaries.

→

Plan

atlas plan

Close today so tomorrow starts clean.

↻

That's it

Run atlas catch "an idea" any time to capture without breaking flow, and atlas session end when you're done. The loop repeats itself.

Why Atlas (ADHD-first)

  • Streak Tracking — visual motivation through consecutive-day tracking
  • Time Blindness Helper — gentle time cues without breaking flow
  • Celebration Helper — positive reinforcement on real progress
  • Context Restoration — "Last time you were…" on session start
  • Anti-Perfectionism — "Good enough" session endings that actually ship
